# Security Policy

Momentum stores your Nextcloud app password and encryption password in the system
keyring through the Secret portal, never in plain files. Sync traffic goes only to the
server you configure.

If you find a vulnerability, please email race-unbent-water@duck.com rather than opening a
public issue. You will get a reply within a week. Fixes ship as a patch release with credit
in the changelog unless you prefer otherwise.
