Momentum

Plan your day. A native GNOME task planner that syncs with Super Productivity.

Install Momentum

Opens in GNOME Software or KDE Discover. Updates arrive automatically.

Or from the terminal

flatpak install --user https://dan-hart.github.io/momentum/momentum.flatpakref

To add the repository only:

flatpak remote-add --user --if-not-exists momentum https://dan-hart.github.io/momentum/momentum.flatpakrepo

Builds are signed; the public key is momentum.gpg. Source, issues and releases live on GitHub.
