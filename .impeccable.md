## Design Context

Momentum is a personal desktop task planner for capturing work, planning the day,
and completing tasks without losing keyboard speed. The user's direction is a
native macOS experience with the quality, clarity and delight of Apple's own apps.

### Personality

Calm, precise, encouraging. Completion should feel satisfying without scores,
streak pressure, distracting celebrations or extra steps.

### Aesthetic direction

Follow Apple's current macOS Human Interface Guidelines. Use system typography by
default, preserve the user's font/size choices, follow light/dark appearance and
the system accent. Keep native lists, selection, menus, checkboxes and sheets.
Reserve glass for transient controls and system chrome. Task content stays quiet.

### Principles

1. Task titles lead; metadata supports them. Use spacing and type before decoration.
2. Make capture immediate and give brief feedback without interrupting typing.
3. Use motion to explain change; respect Reduce Motion and Reduce Transparency.
4. Preserve keyboard operation, drag/drop, localization and scalable typography.
5. Keep core task/sync behavior shared and the handoff/MVP requirements intact.
