# Retained upstream notices

These files retain original upstream license/copyright/notice bytes. Their sources
and SHA-256 hashes are recorded in [provenance.json](provenance.json), and checked
when generating the APK/AAB notice asset. They supplement dependency artifact
notices and Rust package licenses; they do not relicense upstream code.

Apache-2.0 supplies the full license used by JNA, Kotlin/coroutines and AndroidX.
JNA's license-choice notice and its native libffi MIT notice are retained separately.
Kotlin/coroutines attribution notices and UniFFI's full MPL-2.0 license supplement
artifacts/crates which provide license declarations without a full license file.
